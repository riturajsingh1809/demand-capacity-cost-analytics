# Demand, Capacity & Cost Analytics

*Developed by Ritu Raj Singh*

## Project Overview

This project analyzes demand, application volume, peak periods, infrastructure requirements, and cost to support data-driven capacity planning.

The analysis focuses on identifying demand patterns, understanding placement-season peaks, forecasting upcoming demand, and estimating infrastructure requirements at 2x, 5x, and 10x scale.

## Data Preparation

The raw dataset was cleaned and prepared using *Microsoft Excel*. Data quality checks included duplicate removal, missing-value treatment, date standardization, numerical validation, and consistency checks.

The cleaned dataset was then used for Python-based analysis and Tableau visualization.

## Tools & Technologies

* Microsoft Excel – Data Cleaning
* Python – Data Analysis & Forecasting
* Pandas & NumPy – Data Processing
* Matplotlib – Analytical Validation
* Tableau – Dashboard & Visualization
* GitHub – Project Documentation

## Analysis Performed

* Daily and monthly demand analysis
* Traffic and application trend analysis
* Peak and normal-period comparison
* Placement-season demand analysis
* Regional and platform-level analysis
* Moving-average demand forecasting
* Forecast backtesting
* 2x, 5x, and 10x capacity projection
* Infrastructure cost projection
* CPU and storage requirement analysis
* Demand variability and risk assessment

## Dashboard

The Tableau dashboard presents key KPIs, demand trends, peak-period analysis, regional demand, and capacity-cost projections in an interactive format.

## Key Outcome

The project provides a structured analytical approach for understanding future demand and estimating the infrastructure capacity and cost required to support different growth scenarios.
